Just wanted to quickly write about a few changes I've made to the site.

I've made some minor text changes in several places to clean things up, along with a few light CSS adjustments on certain pages. If this is your first time visiting the site, you probably won't notice any of these changes.

More importantly, I've added a games page! The first game I've added is blackjack, and it's made up mostly of assets from [Kenney.nl](https://kenney.nl/). I've been following the people behind the site for quite a while, and I've really wanted an excuse to put some of their assets to use.

It's genuinely a great resource if you're looking for a starting point for any game-related project, and I seriously encourage you to check it out.

Going forward, I plan to keep adding more small browser games to the site, mostly just for fun.
